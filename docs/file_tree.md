# Repository file structure

โปรเจกต์หลักอยู่ที่ root ของ repository; ชุดเริ่มต้นเดิมอยู่ใน `archive/initial-scaffold/` และเก็บไว้เพื่ออ้างอิงประวัติ

      README.snapshot.md
      backend/
        .gitkeep

        queries.sql

        .gitkeep
      frontend/
        .gitkeep
  database/
