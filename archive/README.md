# Archived initial scaffold

ไฟล์ใน `initial-scaffold/` เป็นชุดเริ่มต้นเดิมของ repository และ README snapshot ก่อนจัดโครงสร้างใหม่ เก็บไว้เพื่ออ้างอิงประวัติ

โปรเจกต์ที่ใช้งานปัจจุบันอยู่ที่ root ของ repository อ่าน [README หลัก](../README.md) แล้วรัน npm ที่โฟลเดอร์ซึ่งมี `package.json`

SQL เดิมใน `initial-scaffold/database/` ใช้ฐานข้อมูล `sports_club` และโครงสร้าง ID ต่างจากโปรเจกต์ปัจจุบัน ส่วน SQL ที่ใช้งานคือ `database/` ที่ root และฐานข้อมูล `sports_club_booking`

อย่านำ SQL สองชุดมารันปนกัน และอย่าใช้คำแนะนำ MySQL ใน README snapshot กับโปรเจกต์ SQL Server ปัจจุบัน
