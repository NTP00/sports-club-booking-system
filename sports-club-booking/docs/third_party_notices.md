# Bundled third-party assets

Noto Sans Thai font files are distributed through @fontsource/noto-sans-thai 5.3.0 under the SIL Open Font License 1.1. The full license is retained at src/public/fonts/LICENSE.txt. Fonts are served locally so Thai UI remains readable without a CDN or internet connection.

Node dependencies are listed in package.json, locked in package-lock.json and installed using npm ci. node_modules is intentionally excluded from the ZIP.
